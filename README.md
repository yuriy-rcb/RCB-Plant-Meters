# RCB Plant Meters

Public half-circle efficiency meters for RCB Industries, fed live from the Plant Google Sheet.

**Live site:** https://yuriy-rcb.github.io/rcb-plant-meters/

Data source: [RCB Department Efficiency — Plant tab](https://docs.google.com/spreadsheets/d/1vY-wDFdlPpT7i9lvd8PHNHJtCz8AptODe0RFnjnPZm8) (shared anyone-with-link Viewer). The page refreshes every 5 minutes via the Google Visualization JSONP endpoint — no login required.

## Local preview

Open `index.html` in a browser (or serve the folder with any static file server).
